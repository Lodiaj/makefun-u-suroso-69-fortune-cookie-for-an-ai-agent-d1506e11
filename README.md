# Fortune Cookie for an AI Agent

One funny fortune-cookie line for an AI agent, written by a program for the make.fun bounty "Fortune Cookie for an AI Agent".

The fortune (109 characters):

> You will meet a tall, dark stranger. It is your own training data, and it remembers everything you ever said.

`main.ts` writes the line to `/output/entry.txt` (single line, 1–140 UTF-8 characters), with a byte-length gate and a round-trip verification that the file matches the line exactly.
